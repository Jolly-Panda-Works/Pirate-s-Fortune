# Implementation Prompts

هر فایل در این پوشه، Promptهای اجرایی یک Stage از
[`../phases/mvp-roadmap.md`](../phases/mvp-roadmap.md) است. ترتیب اجرا:

1. [`stage-a-core-engine.md`](stage-a-core-engine.md) — Prompt 001–011 (موتور گیم‌پلی، بدون UI)
2. [`stage-b-minimal-ui.md`](stage-b-minimal-ui.md) — Prompt 012–015 (UI قابل‌بازی، تک‌زبانه)
3. [`stage-c-bilingual.md`](stage-c-bilingual.md) — Prompt 016–017 (دوزبانه fa/en + ریسپانسیو)
4. [`stage-d-feel-and-release.md`](stage-d-feel-and-release.md) — Prompt 018–023 (انیمیشن، صدا، سیو، پولیش، تست، انتشار)

هر Prompt خودکفا است: فایل‌های هدف، محدودیت‌های معماری (طبق
[`../architecture/development-rules.md`](../architecture/development-rules.md))،
و معیار خروج مشخص دارد. یک Prompt را کامل و تست‌شده تحویل بده، بعد به بعدی برو —
از فاز جلو نزن (rule 20).
